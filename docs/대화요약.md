# 설계 과정 및 결정 사항 요약

## 공통 구성
- 외함: 하이박스 500 x 600 x 200, 경첩 좌 / 걸쇠 우 (경첩 t=130, 530 / 걸쇠 t=300)
- 기기: LS 전자접촉기 x4 (MC1~4), Sonoff 4CH Pro R3 (145 x 90 x 34), ELB 2P SIE-32 20/30A (70 x 32 x 39)
- 전원: Main 분전반 (KR 계통) → ELB 1차측 (KIV 4SQ x2)
- 주회로: SUB 분전반 (Grid Simulator) → MC1~4 → 부하1~4 (MAIN/SUB 분전반은 나란히 위치)
- 제어 배선 (HIV 1.5SQ): ELB → Sonoff L/N, L → COM1~4 점프, NO1~4 → MC A1, A2는 N 공통 점프
- 코일 단자 A1(좌) / A2(우)는 접촉기 상단

## 타공 및 케이블 그랜드
- 좌측면: Ø30 x1 (220V 인입, 상단 46), Ø50 x2 (SUB 분전반 인입, 240 / 320)
- 하단면: Ø50 x4 (부하 출력, 중심 79 / 193 / 307 / 421 — 접촉기 중심과 일치)
- 깊이 방향 타공 중심 100 (가정)
- 그랜드: Ø30 → PG21 (나사 28.3 / 너트 33), Ø50 → PG36 (나사 47 / 너트 52)
  - 고정용이 아닌 마감용이라 약간 헐거워도 OK, 조일 때 중심 맞추고 필요 시 와셔 추가
  - Ø48 홀쏘는 구하기 어려워 Ø50 유지, PG42(나사 54)는 안 들어감

## MC-85A 버전
- 접촉기 94 x 140 x 172.3, 간격 20
- 주회로 KIV 16SQ (외경 약 9mm), 접촉기당 3선 → Ø50 그랜드 통과
- 깊이 여유 27.7 → 업체 확인 필요 (도면에 적색 표기)

## MC-40A 버전
- 접촉기 69 x 83 x 90, 3P 2a2b, 간격 45 (하단 타공 중심과 정렬), M4 취부
- 주회로 16SQ → 4SQ 전부 변경, 타공 규격은 MC-85A와 동일 (업체 일괄 가공)
- 깊이 여유 110 (도어 간섭 없음)
- 주의: 4SQ KIV 허용전류(약 30A대) < 정격 40A → 부하전류 확인 필요

## 기타 메모
- ELB 20/30A는 Sonoff 제어전원용으로는 용량 과다 (참고)
- 정면도 치수는 W/D/H 없이 숫자만 표기 (예: 69 x 83 x 90)
